# Fit Linear Geographic Label to Feature Path

## Pattern Rule
**IF** a narrow linear geographic feature needs a name that must remain clearly associated with its path
**THEN** use the feature course as the directional scaffold for the label, curve the lettering with the broad path, control letter height with a parallel guide when needed, and spread the name far enough along the feature to make the association clear

## Do
- Establish the broad feature path before lettering.
- Follow broad curvature rather than every small local wiggle.
- Use a light parallel guide when the label needs controlled height along the curve.
- Distribute the name along enough of the feature that the reader reads text and feature as one association.

## Don't
- Do not set a linear-feature name on an unrelated straight baseline when the feature direction is part of the association.
- Do not force letters through tight local bends that damage readability.
- Do not let the label drift so far from the path that ownership becomes ambiguous.

## Checklist
- The label follows the feature’s dominant path.
- Letter height and spacing remain readable along the curve.
- The named feature is unambiguous without a leader line.
- Local path irregularities do not distort the text.

## Notes
Linear geographic labels use the mapped feature itself as a text scaffold. This differs from point-location labels, which stay straight and close to one discrete icon.
