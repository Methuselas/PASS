# Calibrate Running Text as a Coupled Type Size, Measure, Leading, and Spacing System

## Pattern Rule
**IF** a publication contains sustained running text that must remain comfortable across many lines or pages
**THEN** test the chosen face at actual output size and tune apparent type size, letterspacing, wordspacing, paragraph measure, and leading as one coupled system until the text forms an even readable texture, line returns are easy to find, and spacing defects do not interrupt comprehension
**ELSE** keep shorter display or support text on the typographic treatment appropriate to its own role rather than forcing body-text proportions onto it.

## Do
- Judge apparent size from the drawn letterforms at output scale, especially x-height, stroke weight, ascenders, and descenders; equal point sizes do not guarantee equal perceived size or reading comfort.
- Use character count as a practical starting test for measure rather than relying on physical width alone. For ordinary mature-reader body text, roughly fifty to eighty characters including spaces is a useful initial range, not a universal target.
- Keep wordspaces only large enough to distinguish words. Repeated large gaps can align into rivers that compete with the intended left-to-right or sequential reading path.
- Adjust letterspacing when scale changes materially. Very small type may need more separation for character recognition, while large type may need tighter spacing to retain a coherent word shape.
- Set leading in relation to type size, x-height, ascender/descender depth, and line length. Dense faces and wider measures generally need more interline space so the eye can locate the next line cleanly.
- Prototype several paragraph settings by changing one or more coupled variables, compare them at actual size, and select one body-text standard before deriving column widths and subordinate text roles from it.
- Treat excessive hyphenation, rivers, line collisions, an indecisive rag, or repeated difficulty finding the next line as evidence that the system needs recalibration rather than as isolated cosmetic defects.

## Don't
- Do not specify body text by nominal point size alone.
- Do not lock paragraph width before checking how the selected typeface and size actually populate a line.
- Do not fix a spacing problem by changing one variable mechanically while ignoring its effect on the others.
- Do not accept tight leading merely because it saves pages when ascenders, descenders, or neighboring lines begin to interfere with reading.
- Do not make the body-text standard so specialized to one sample paragraph that ordinary longer, shorter, or differently worded passages fail immediately.

## Checklist
- The body face is legible and comfortable at actual output size.
- Letterspacing and wordspacing produce an even rhythm without obvious dark clumps or rivers.
- Measure supports a manageable line length for the intended reader and type size.
- Leading gives each line enough separation for a reliable return without breaking the paragraph into unrelated stripes.
- The chosen paragraph standard survives several representative passages rather than one ideal sample.
- Column and page decisions derived from the body-text standard do not force repeated typographic repair.

## Notes
Running text is not a collection of independent settings. Apparent type size changes with the drawing of the face; spacing changes with scale; useful leading changes with density and measure; and measure changes how many words and characters the reader must process before returning to the next line. Calibrating these variables together produces the stable paragraph texture from which the rest of a publication's text system can be built. Numeric ranges are starting points for testing, not substitutes for optical judgment at the intended output size.
