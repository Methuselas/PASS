# Package Final Publication Files for External Print Handoff

## Pattern Rule
**IF** a completed publication layout is ready to leave the designer for commercial print production
**THEN** package one unmistakable current master with every required linked asset and production instruction according to the selected printer's current specifications, then provide a stable marked reference copy that identifies exceptional colors, images, or manufacturing details
**ELSE** keep the layout in design review until temporary assets and unresolved production requirements are cleared.

## Do
- Ask the printer for its current requirements for document format, bleed, crop marks, color handling, image resolution, fonts, and packaging before export.
- Keep one clearly identified current layout file; archive earlier versions with explicit version labels so production cannot select an obsolete master by mistake.
- Gather the current layout, linked artwork, fonts or other required resources, and pertinent support files into the printer's requested package.
- Replace temporary low-resolution or position-only images before release, and remove unused special colors that could create accidental separations or manufacturing confusion.
- Recheck page count against the selected binding or signature structure before files leave the designer.
- Mark spot colors, images needing special attention, and unusual production instructions directly on a stable reference copy rather than relying on detachable notes.

## Don't
- Do not send multiple files that are each named as though they are the final master.
- Do not assume a file format, color space, resolution target, or printer-mark setup is universal across vendors and processes.
- Do not release placeholder images, missing links, unused production colors, or unexplained exceptions and expect prepress to infer the intended fix.
- Do not make critical manufacturing instructions dependent on loose notes that can be separated from the job.
- Do not skip a final page-count check when the binding imposes a specific folding or leaf structure.

## Checklist
- The printer can identify one current layout master without ambiguity.
- Every required linked or supporting asset is present in the handoff package.
- Temporary images and unused production colors have been resolved.
- Page count is compatible with the selected binding or signature structure.
- Export and packaging follow the selected printer's current technical requirements.
- The reference copy clearly identifies every exceptional production requirement that cannot be inferred safely from the files alone.

## Notes
Prepress mistakes often begin as handoff mistakes: stale masters, missing links, temporary images, unclear color instructions, or generic export settings that do not match the actual printer. Final delivery is therefore a controlled transfer, not merely an export command. Keep the working files orderly throughout the project, then package the current master and its dependencies to the receiving printer's specification and accompany them with unambiguous production markup.
