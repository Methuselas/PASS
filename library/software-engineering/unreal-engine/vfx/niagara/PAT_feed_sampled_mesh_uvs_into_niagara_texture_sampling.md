# Feed Sampled Mesh UVs into Niagara Texture Sampling

## Pattern Rule
**IF** a texture sampled in Niagara must line up with the surface of a sampled mesh
**THEN** feed the mesh sample's UV output into the Sample Texture UV input.

## Do
- Use the UV parameter generated by Sample Static Mesh.
- Bind that parameter to Sample Texture UV.

## Don't
- Do not sample unrelated coordinates when the texture must correspond to the mesh mapping.

## Checklist
- Texture-driven behavior aligns with the mesh's mapped image.

## Notes
A typical mesh-sampling path exposes the UV output as Particles.SampleStaticMesh.MeshUV.
