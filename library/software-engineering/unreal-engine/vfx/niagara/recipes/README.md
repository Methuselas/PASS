# Niagara Recipes

This directory is the self-contained VFX recipe library for Unreal Engine Niagara.

- A **Recipe** is stored as a PASS Pattern (`PAT_...`). It must contain everything needed to execute that implementation without opening another recipe or the source it was learned from.
- A **Composite Recipe** is stored as a PASS Action Protocol (`AP_...`). It repeats the constituent build steps it needs instead of depending on child recipes.
- A **Drill** (`DRILL_...`) may be added beside a family when a repeatable exercise is useful for learning or verification.
- Families own their numbering. `variant_01` in `fire/` is unrelated to `variant_01` in `sparks/`.
- Visual style is indexed by tags: `style_realistic`, `style_stylized`, `style_hybrid`, or `style_agnostic`.
- Engine baselines and verified compatibility are recorded in card tags/Notes. A recipe is not marked compatible with a later Unreal release until it is tested there.
- Recipe cards carry no book, video, page, URL, or source identity. Source provenance belongs to the PASS run/evidence that produced or refined the card, not to the runtime skill object.

`INDEX.md` files are generated by `PASS/tools/build_index.py`; do not hand-edit them.
